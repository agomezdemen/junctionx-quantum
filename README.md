# JunctionX

A minimal Python starter. Requires Python 3.10 or newer; no dependencies.

## Run

```bash
python3 main.py
```

Start building in `main.py`. Project metadata lives in `pyproject.toml`.

## Optional virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows, activate with `.venv\Scripts\activate`.
